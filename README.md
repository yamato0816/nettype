# NET/TYPE v3

16タイプの各解説（特徴・癖・場面・周囲の見方）を追加した版。

**使い方**：`nettype_standalone.html` をブラウザで開くか、`index.html` `styles.css` `app.js` を同じ場所に置いて開きます。Web公開ならこれら3ファイルを静的ホスティングにアップロードしてください。

トップページの16タイプカードをクリックすると各キャラの詳しいプロフィールへ移動します。診断を最後まで進めても同じ文章が表示されます。全文章は `16types_guide.md` に収録しています。

元の28問・判定方法・共有リンクとの互換性は維持しています。現状は娯楽用診断であり、決済機能はありません。
